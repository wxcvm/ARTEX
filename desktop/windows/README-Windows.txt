ARTEX Windows 桌面客户端（便携版）
================================

程序图标：ARTEX 使用银色鹰首盾牌标识，网页、Windows 桌面窗口、任务栏、快捷方式和安装器使用同一品牌图案。
Windows 多尺寸 .ico 由 desktop/windows/generate-icon.ps1 根据 web/public/logo.jpg 自动生成。

运行方法：四步即可开始（无需手工复制 config.json）
1. 正常运行 ARTEX.Desktop.exe，点击“自动准备本机数据库”。
   优先验证原连接；不可用时备份旧配置并准备独立新库，不迁移旧任务，原服务不变。
   没有 PostgreSQL 程序时点安装按钮，按当前步骤的详细指南完成官方安装后返回。
2. 设置 ARTEX 登录密码。桌面自启后端自动取得一次性令牌，不需要翻日志。
   外部后端和浏览器使用仍保留手动入口；密码不是数据库密码或 API Key。
3. 填写模型协议、接口地址、模型名、API Key，点击“测试并启用”。
   测试会发送真实模型请求；实际回复成功后保存并激活。已有配置可保留，不会自动测试。
4. 进入任务页自行创建、检查并启动任务；也可先浏览知识库。

每一步都有简短说明和可展开的六部分详细指南；菜单“开始使用 / 配置引导”可重开。
“已有数据库 / 高级设置”保留所有连接参数、单独测试及创建入口，保存前必须验证。
ARTEX_PG_DSN 环境变量优先，存在时验证该连接，不保存不会生效的覆盖配置。
独立数据库位于 %LOCALAPPDATA%\ARTEX\PostgreSQL\16\，仅本机监听 15432–15442 可用端口。
管理凭证使用当前 Windows 用户 DPAPI 保护；不要以管理员身份运行 ARTEX。
失败后直接重试，原账户密码、服务与旧数据库不会重置；未完成目录保留供排查。
退出时先停止自启后端，再正常停止自启数据库；外部服务不会停止。

使用说明：
- Windows 11 通常已包含 Microsoft Edge WebView2 Runtime。
  若缺少该运行时，请从微软官方获取并安装。
- 桌面版基于 .NET 10，随包发布的 ARTEX.Desktop.exe 为自包含版本，
  无须再安装单独的 .NET Desktop Runtime。
- 点击窗口右上角 X 或最小化会将程序收进托盘；
  通过托盘菜单或顶部「更多 → 退出 ARTEX」真正结束客户端。
- 若桌面客户端自行启动了后端，退出时也会停止它；
  如果连接的是已经运行的后端，退出不会停止既有服务。
  正在执行的任务可能因后端停止而中断。
- WebView2 的浏览器数据及后端日志位于：
  %LOCALAPPDATA%\ARTEX\
- 默认 Web/API 仍可通过 http://127.0.0.1:8787 访问。
- 顶部工具栏保留后退、前进、刷新、全屏和「在浏览器打开」。
  「更多」中提供数据库配置、打开配置目录、重新连接及退出，适合高 DPI 窄窗口。
  “打开配置目录”打开程序所在目录，便于修改数据库配置。
- 桌面窗口提供可选的 PostgreSQL 官方安装入口；安装程序独立运行，
  不内置数据库程序或默认密码，不自动更改已有数据库服务；独立库由向导管理。
  可手动初始化普通 artex 专用账户及其新数据库，或选择只创建缺失的目标数据库。
  专用账户不具有 SUPERUSER、CREATEDB、CREATEROLE 权限。
  管理服务可能需要 Windows 管理员权限；原有数据库和账户不会被重置。
- 可选知识库随包附带 knowledge\knowledge.db。要让 Agent 使用只读检索工具，
  在 config.json 设置 "knowledge_dir": "D:/Apps/ARTEX/knowledge"（按实际安装路径修改），
  或将环境变量 ARTEX_KB_DIR 设置为该目录的绝对路径。
- 不要只复制 ARTEX.Desktop.exe，桌面包中的 artex.exe、skills、knowledge 及配置
  模板应一并保留。
