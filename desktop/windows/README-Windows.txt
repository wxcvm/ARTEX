ARTEX Windows 桌面客户端（便携版）
================================

运行方法（无需手工编写 config.json）：
1. 将完整安装包解压至可写目录（例如 D:\Apps\ARTEX），运行 ARTEX.Desktop.exe。
2. 第一次打开时自动检查本机 PostgreSQL：
   - 已安装：确认检测到的端口，填入安装 PostgreSQL 时设置的 postgres 管理员密码。
     选择「本机安装 · 推荐」，点击「初始化并连接」。向导会在你确认后调用
     ARTEX 后端现有的专用账户初始化功能，创建普通 artex 账户与新数据库，
     保存生成的专用连接信息，随后自动尝试启动后端。如果专用账户
   创建成功但保存配置遇到权限问题，修正写入问题后再次点击同一按钮
   会仅重试保存，不会再次创建账户。
   - 未安装：点击「安装 PostgreSQL」，完成官方交互安装后再点「检测本机」。
     软件不会自动设置管理员密码或修改已存在的账户。
   - 已经有自己的 PostgreSQL 用户、现成数据库或远程服务器：
     选择「已有账户 / 远程连接」，填写连接信息，可先测试数据库连接，
     也可按需创建缺失的目标数据库。
3. 如果启动失败，中央的恢复界面提供「修复数据库连接」「重新连接」
   和「查看日志」。技术详情可以展开，不必先查找日志路径。
4. 如果你已经配置过数据库，原有 config.json 会保留，修改连接时
   仍保留其他配置字段；ARTEX_PG_DSN 环境变量始终优先于文件配置。
   当该环境变量存在时，向导会明确提醒：仅保存配置文件不能覆盖它，
   需要修改或移除变量并重启 ARTEX。

说明：推荐模式是引导流程，而不是内置数据库；PostgreSQL 仍需在本机安装
或使用远程服务，并需要填写有效的管理员密码。专用账户初始化仅面向新部署；
已经存在同名账户或数据库时不会擅自覆盖。
使用说明：
- Windows 11 通常已包含 Microsoft Edge WebView2 Runtime。
  若缺少该运行时，请从微软官方获取并安装。
- 桌面版基于 .NET 10，随包发布的 ARTEX.Desktop.exe 为自包含版本，
  无须再安装单独的 .NET Desktop Runtime。
- 点击窗口右上角 X 或最小化会将程序收进托盘；
  通过托盘或窗口内“退出”真正结束客户端。
- 若桌面客户端自行启动了后端，退出时也会停止它；
  如果连接的是已经运行的后端，退出不会停止既有服务。
  正在执行的任务可能因后端停止而中断。
- WebView2 的浏览器数据及后端日志位于：
  %LOCALAPPDATA%\ARTEX\
- 默认 Web/API 仍可通过 http://127.0.0.1:8787 访问。
- “打开配置目录”打开程序所在目录，便于修改数据库配置；
  “在浏览器打开”继续保留传统网页使用方式。
- 桌面窗口提供可选的 PostgreSQL 官方安装入口；安装程序独立运行，
  不内置数据库、默认密码或自动更改数据库服务。
  可手动初始化普通 artex 专用账户及其新数据库，或选择只创建缺失的目标数据库。
  专用账户不具有 SUPERUSER、CREATEDB、CREATEROLE 权限。
  管理服务可能需要 Windows 管理员权限；原有数据库和账户不会被重置。
- 可选知识库随包附带 knowledge\knowledge.db。要让 Agent 使用只读检索工具，
  在 config.json 设置 "knowledge_dir": "D:/Apps/ARTEX/knowledge"（按实际安装路径修改），
  或将环境变量 ARTEX_KB_DIR 设置为该目录的绝对路径。
- 不要只复制 ARTEX.Desktop.exe，桌面包中的 artex.exe、skills、knowledge 及配置
  模板应一并保留。
